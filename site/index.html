    Built for Claude

    A companion MCP server, not a copy-paste workaround.

    Claunote ships a second, purpose-built container that speaks the Model Context Protocol — it's a thin client of Claunote's own API, so every tool call goes through the exact same search indexing, title handling, and collision rules as the web app itself.

    Nothing to generate by hand: open Settings (the gear icon in the sidebar) and a bearer token is already waiting, along with the exact connect command, a one-click regenerate, and a Connected/Disconnected switch that cuts off access instantly without touching the token itself.

    This needs a real public domain to actually work with Claude — Claude Code, Claude Desktop, and claude.ai all run outside your own network, so a Tailscale-only or LAN-only address (fine for the web app itself) can't be reached for the MCP connection. See Security for how that's hardened for exactly this.

    # Claude Code — command is pre-filled in Settings, ready to copy
claude mcp add --transport http claunote \
  https://your-domain/mcp \
  --header "Authorization: Bearer <from Settings>"

    Why

    Your notes are just files. That's the whole idea.

    Claunote keeps your notes as plain markdown files on disk — no database, no proprietary format, nothing you can't open in any other editor the moment you stop using this one.

    There's no account system, no subscription, and no third-party server holding your notes. It's one container, one folder of .md files, and a full GitHub Flavored Markdown editor that works the same on your phone and your laptop.

    What you get

    A full markdown editor, without the baggage.

    ▦

    No database

    Every note is a .md file. Move it, back it up, or read it with any other tool — nothing is locked away.

    ✎

    Full GFM support

    Tables, footnotes, task lists, and GitHub-style callouts — the whole spec, not a subset.

    ⏎

    Blank lines that stay

    Press Enter three times and the extra empty line is really there — saved as a literal <br> line in the markdown, so GitHub renders it the same way. Most editors silently collapse anything beyond one blank line.

    ⊗

    Zero-dependency editor

    A small hand-written markdown converter, not a third-party library loaded from a CDN — nothing external to version-mismatch or break.

    ◆

    Self-hosted

    Runs in one Docker container. Your notes live on your own disk, not someone else's server.

    ◐

    Dark mode

    Follows your system preference automatically. No setting to hunt for.

    ⇅

    Import / export

    One click exports every note and attachment as a dated zip. Import it right back in, always yours to take.

    ▦

    Installable PWA

    Add it to your home screen. Use it like a native app, on desktop or mobile.

    Security

    Built assuming it's reachable from the internet.

    Built assuming it might sit on a public VPS behind a real domain, and hardened accordingly: Argon2id password hashing with enforced strength, optional two-factor authentication, opaque server-side sessions, per-IP login rate limiting, path-traversal-safe title handling, zip-bomb-capped imports.

    🔒

    Locked-down containers

    Both the app and the MCP server run with every Linux capability dropped, no-new-privileges, a read-only root filesystem, and memory/PID limits — and bind to 127.0.0.1 only, so a reverse proxy is required rather than optional.

    🔐

    Mandatory MCP auth

    The MCP container refuses to start without a bearer token, checked in constant time, with its own per-IP rate limit independent of the reverse proxy in front of it.

    🔒

    HSTS by default

    Sent automatically whenever cookies are running in secure mode — the same signal already used for the session cookie's Secure flag.

    🛡

    Non-root, patched weekly

    Both images run as an unprivileged user, and rebuild on a weekly schedule so OS-level security patches land even without an app change.

    🔐

    Enforced password strength

    Minimum 10 characters with an upper/lower/digit/symbol mix, checked on first boot and every later change — not just a length count.

    🔒

    Optional two-factor authentication

    Standard TOTP, set up from Settings with a QR code — plus one-time backup codes, Argon2id-hashed, for account recovery if you lose the authenticator.

    Get started

    Running in about two minutes.

    Claunote ships as a Docker image. Point it at two folders on disk — one for your notes, one for the app's own small bit of state — and it takes care of the rest.

    # docker-compose.yml
services:
  claunote:
    image: ghcr.io/lightmorphic/claunote:latest
    container_name: claunote
    restart: unless-stopped
    environment:
      NOTES_USERNAME: "admin"
      NOTES_PASSWORD: "changeMe!"
    volumes:
      - /opt/media/notes:/notes
      - /opt/claunote:/data
    ports:
      - "127.0.0.1:8080:8080"
    1. Create the data folders — sudo mkdir -p /opt/media/notes /opt/claunote
    2. Start the containers — docker compose up -d (the MCP server comes in the same file, see the README for its setup)
    3. Put a reverse proxy in front — ports bind to 127.0.0.1 only by design; add nginx, Caddy, or Tailscale Serve for TLS and open it up
